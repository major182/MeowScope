# 猫の体調管理アプリ（MeowScope）

## はじめに

- 本リポジトリは、猫の体調管理アプリ「MeowScope」に関するものです
- 利用者は開発者に限っており、一般公開はしていません（[利用方法](#利用方法)）
- Ver.1.1 までの実装とテスト（単体・結合・E2E・性能）を終え、開発者の PC のサーバー（Tailscale の VPN の中だけ）で動かして利用者の端末でのみ使用が可能な段階です

## コンセプト

- いざという時に、猫の様子がいつもと何が違うかを判断できるようにする
- 利用者が猫のために適切に判断できるツールにする

## アプリ概要

- 日々の食事・飲水・投薬・排尿・排便・嘔吐・体重・ブラッシング・通院を記録し、カレンダーや統計で確認できるアプリです
- Windows desktop と Android スマートフォンで使えます
- 記録はサーバーに保存して、おうちの利用者どうしで共有します。通信できないときやサーバーが止まっているときも端末に記録でき、つながったら同期します

### 主な機能（Ver.1.0〜Ver.1.4.0）

| 区分 | 機能 |
|---|---|
| 記録 | ご飯・水・薬・おしっこ・うんち・吐いた・体重・ブラッシング・病院、独自の項目、詳細の入力、写真（画面いっぱいに広げて拡大）、メモ。カレンダーの日付から、記録し忘れた日の記録を追加。記録のボタンは並べ替えられる |
| 病院（Ver.1.3.0） | 通院・入院・ワクチン・検査を、病院の名前（前に入れた名前から選べる）と次の予定日とともに記録。予定日はカレンダーに印を出し、猫のプロフィールに病院の履歴を出す |
| 見る | 1か月分のカレンダー（週の始まりは日曜・月曜を切り替え、誕生日と病院の予定の印）、日ごとの一覧、メモの言葉・項目・猫・期間で過去の記録を検索 |
| 統計 | 回数の推移と体重のグラフ（週・月）。体調のようす：その日の値を、その猫のいつもの範囲と並べ、外れ値を上にまとめる。Windows では、期間を自由に決め、2匹以上の猫や項目の線を重ね、時間帯の傾向と日ごとの表も見られる（Ver.1.4.0） |
| いつもとの差 | 直近の傾向と比べて、いつもと違う回数や体重の変化を自動で見つけて知らせる |
| 通知 | 投薬の予定・いつもとの差・記録忘れ・おうちの他の利用者の記録・猫の誕生日。種類ごとにオフにできる |
| 共有 | 「おうち」に複数の猫と利用者を登録し、LINE などで渡すリンクで招待。1人で2つ以上のおうちに入り、切り替えて使える（Ver.1.4.0） |
| CSV の出力（Ver.1.4.0） | Windows で、期間・猫・項目を選んで記録を1件1行の CSV に保存（Excel で開ける） |
| Android のウィジェット | 登録したボタンで「ご飯食べた」などをワンボタンで記録。おうちごとに置ける |
| オフライン | 通信できないときも記録し、つながったら同期 |
| アカウント | メールアドレスとパスワードでログイン、メールの確認コードでパスワードを再設定、アイコンの設定（切り抜く範囲を選べる） |
| 問い合わせ | エラーの画面に問い合わせ番号を出し、端末のログをサーバーと同じ場所で追える |
| アプリの更新（Ver.1.1） | 起動したときと設定の画面で新しい版を確かめ、選ぶと取ってきて入れ直す。今の版をログインと設定の画面に出す |

## 環境

| 区分 | 技術 |
|---|---|
| アプリ | Flutter 3.47.9（Dart 3.13.7）、Riverpod、go_router、dio、drift（SQLite）、fl_chart |
| Android のウィジェット | Kotlin、home_widget |
| サーバー | Java 25、Spring Boot 4.1.2（Spring Security、Flyway） |
| データベース | PostgreSQL 18.6 |
| インフラ | Docker Compose。開発者の PC の Docker Desktop で動かし、Tailscale の VPN の中だけに HTTPS で出す（Ver.1.3.1 から、サーバーの名前は独自ドメインの `meowscope-api.meowscope.dev`。Caddy が証明書を取る）。AWS EC2（Caddy で HTTPS）で動作を確かめた後に移した（AWS の環境は消した） |
| CI | GitHub Actions（静的チェック・テスト・カバレッジ・OSV-Scanner による脆弱性検査） |
| テスト | 単体・結合（Testcontainers）・E2E（integration_test）・性能（k6） |

- 採用の理由は [技術選定書](docs/02_tech-stack.md) にまとめています
- デプロイの構成と手順は [デプロイ設計書](docs/09_deployment.md) にまとめています
- アプリの説明・プライバシーポリシー・アカウントの削除の案内は、[MeowScope の Web サイト](https://meowscope.dev/apps/meowscope/) に置いています（ソースは [meowscope-site](https://github.com/major182/meowscope-site)）
- お問い合わせは support@meowscope.dev へお送りください

## 利用方法

- 利用者を限っているため、一般の方は利用できません
- アプリは開発者が利用者の端末に直接入れます（Android は署名した APK、Windows はインストーラー）。サーバーの接続先がアプリに入るため、GitHub Releases には置きません

## 今後の予定

詳しくは [要件定義書 2章](docs/01_requirements.md#2-システム化の概要) にまとめています。

| 版 | 内容 |
|---|---|
| Ver.1.5.0 | アプリを閉じている間のおうちの他の利用者の記録の通知（プッシュ通知） |
| Ver.1.6.0 | 獣医師向けのレポートの出力 |
| Ver.2.0.0 | 生成 AI（Claude API）による記録の分析 |
| 一般公開のとき | 利用規約（今は下書き）とプライバシーポリシーの見直し、招待のリンクをこのアプリだけが開ける https のリンクにする |

- 今は開発者が個人で使うツールですが、将来の一般公開を想定して作っています。公開の時期と、外部のサーバーへのデプロイの方法は、公開すると決めたときに決めます
