## コンセプト

- いざという時に、猫の様子がいつもと何が違うかを判断できるようにする
- 利用者が猫のために適切に判断できるツールにする

## アプリ概要

- 日々の食事・飲水・投薬・排尿・排便・嘔吐・体重を記録し、カレンダーや統計、生成 AI による分析で確認できるアプリです
- Windows desktop と Android スマートフォンで使えるアプリです
- 主な機能は次のとおりです
  - 日々の記録（ご飯・水・薬・おしっこ・うんち・吐いた・体重）
  - 記録のカレンダー表示
  - 統計による分析の可視化
  - 生成 AI を用いた分析
  - Android のウィジェット：利用者が登録したボタンで「ご飯食べた」などをワンボタンで記録
