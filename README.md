# 猫の体調管理アプリ（MeowScope）

## はじめに

- 本リポジトリは、スクールの課題として major182 が作っている猫の体調管理アプリ「MeowScope」に関するものです
- 利用者は開発者を含む2人に限っており、一般公開はしていません（[利用方法](#利用方法)）
- 現在は開発中です。設計を終え、アプリの実装を始めた段階です

## コンセプト

- いざという時に、猫の様子がいつもと何が違うかを判断できるようにする
- 利用者が猫のために適切に判断できるツールにする

## アプリ概要

- 日々の食事・飲水・投薬・排尿・排便・嘔吐・体重・ブラッシングを記録し、カレンダーや統計で確認できるアプリです
- Windows desktop と Android スマートフォンで使えます
- 記録はサーバーに保存して家族で共有します。通信できないときやサーバーが止まっているときも端末に記録でき、つながったら同期します
- 主な機能（Ver.1.0）は次のとおりです
  - 日々の記録（ご飯・水・薬・おしっこ・うんち・吐いた・体重・ブラッシング、独自の項目、写真、メモ）
  - 記録のカレンダー表示（1か月分、週の始まりは日曜・月曜を切り替え）
  - 回数の推移と体重のグラフ（週・月）
  - 「おうち」による共有：複数の猫と複数のユーザーを登録し、リンクで招待
  - Android のウィジェット：登録したボタンで「ご飯食べた」などをワンボタンで記録
  - オフラインでの記録と、後からの同期
- 画面のイメージは [HTML のプロトタイプ](prototype/index.html) で確認できます

## 環境

| 区分 | 技術 |
|---|---|
| アプリ | Flutter 3.47.9（Dart 3.13.7）、Riverpod、go_router、dio、drift（SQLite） |
| Android のウィジェット | Kotlin、home_widget |
| サーバー | Java 25、Spring Boot 4.1.2（Spring Security、Flyway） |
| データベース | PostgreSQL 18.6 |
| インフラ | Docker Compose。AWS EC2 で数日動かした後、開発者の PC の Docker へ移す |
| CI | GitHub Actions（静的チェック・テスト・OSV-Scanner による脆弱性検査） |

- 採用の理由は [技術選定書](docs/02_tech-stack.md) にまとめています

## 利用方法

- 利用者を限っているため、一般の方は利用できません
- 配布は GitHub Releases で行う予定です

## 実装予定の機能

- いつもとの差の自動検知と通知
- 投薬の予定・記録忘れ・家族の記録の通知
- 獣医師向けのレポートの出力
- 生成 AI（Claude API）による記録の分析
- 通院・検査・ワクチンの履歴、過去の記録の検索
