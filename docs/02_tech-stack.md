## 1. この文書の目的

MeowScope で採用する技術、バージョン、選定の理由を記録する。

## 2. 選定の条件

- Windows desktop と Android を対象とし、Android のウィジェットとバックグラウンド処理を作れる
- オフラインで記録でき、サーバーが停止していても動く
- ランニングコストを可能な限り発生させない
- AWS から開発者の PC の Docker へ移しやすい
- LTS がある技術は最新の LTS、ない技術は最新の安定版を使う
- 将来の iOS 対応を妨げない

## 3. 採用技術の一覧

バージョンは 2026-11-02 に公式の配布元で確認した。

|---|---|---|---|---|

| アプリの言語 | Dart | 3.13.7 | Flutter に同梱 | |

## 4. 主な設計判断

- **同期は自作する。** 差分同期、削除の同期、競合の解決（BR-10、BR-11）をサーバーとアプリの両方に実装する
- **守りはサーバーに置く。** アプリは解析される前提で、認証と認可をすべてサーバーで行う（NF-SC-04）
- **OS に依存する部分を分離する。** 検知の判定は Dart の独立した部分に置き、ウィジェットとバックグラウンド処理はアプリ本体から分ける。将来の iOS では、ウィジェットを Swift で作り直し、判定を伴う通知はサーバーからのプッシュ通知を検討する
- **AWS 固有の機能に依存しない。** 移行は Compose の定義、DB のダンプ、写真のボリュームを移すことで行う
- **メール送信はインターフェースで分ける。** 将来の公開時に送信サービスへ差し替えられるようにする。アプリパスワードは秘密の置き場に置く
