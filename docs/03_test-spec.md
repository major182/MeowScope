## 1. テストの区分

| 区分 | 何を確かめるか | 差し替えるもの | 使う道具 |
|---|---|---|---|
| 単体テスト（UT） | 関数・クラス・コンポーネントを単独で | DB・外部 API・他の層 | |
| 結合テスト（IT） | API・画面の単位で、層をつないで | 差し替えない（実際の DB を使う） | |

## 2. 観点の出し方

- 単体：分岐網羅（C1）を目標にする。同値分割・境界値
- 結合：設計書のステータス・エラー・権限（デシジョンテーブル）・状態遷移
