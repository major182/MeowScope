## 1. はじめに

- 目的：猫の日々の体調を記録し、いざという時に、いつもと何が違うかを利用者が判断できるようにする
- 対象とする利用者：開発者を含む限られた利用者（2人を想定）。一般公開はしない

## 2. システム化の概要

- 対象プラットフォーム：Windows desktop、Android スマートフォン
- Android 版はウィジェットを備え、利用者が登録したボタンで「ご飯食べた」などをワンボタンで記録できる
- 記録はサーバーに保存して端末間と利用者間で共有する。通信できないときやサーバーが停止しているときは端末に保存し、サーバーにつながったら同期する

リリースの段階は次のとおりとする。

| 段階 | 範囲 |
|---|---|
| 初回 | 記録、カレンダー、基本の統計、複数猫、家族共有、Android ウィジェット、オフライン記録と同期 |
| 次の段階 | 自動検知、通知、獣医師向けレポート、生成 AI 分析 |
| 第3段階 | 通院・検査の履歴、検索 |
| PC へ移すまで | バックアップ |
| 任意（Must ではない） | CSV 出力 |

## 3. 業務ルール（BR-xx）

| ID | ルール |
|---|---|
| BR-01 | 記録の詳細はすべて任意とする。必須にすると記録が続かないため |
| BR-02 | 同じ項目を1日に何回でも記録できる |
| BR-03 | 生成 AI の分析は診断を行わず、判断の材料と受診の目安の提示に留める |
| BR-04 | 生成 AI へのデータ送信は、利用者が実行の操作をしたときだけ行う。送るのは必要な期間の記録とし、写真は送らない |
| BR-05 | 「いつもとの差」の通知は日本時間の10時ごろに行う。多少の遅れは許容する |
| BR-06 | 投薬の通知は利用者が設定した時刻に行う |
| BR-07 | 検知と通知は端末内で行い、サーバーに依存しない。判定には端末にある記録を使う |
| BR-08 | 家族の記録の通知は、同期で自分以外の記録の更新を受け取ったときに出す |
| BR-09 | 通知は Android で行う。Windows はアプリの起動中に表示する |
| BR-10 | 同じ記録の更新が競合したときは、更新のタイムスタンプが新しい方を採用する（仮のルール） |
| BR-11 | 削除も更新の一つとして同期し、BR-10 に従う |
| BR-12 | 「いつもとの差」の通知の前に、最後の同期が15分以内かを確かめ、超えていれば同期を試みてから判定する |
| BR-13 | 記録忘れは、最後の記録から n 時間が過ぎたときに通知する。n は利用者が設定でき、既定値は10時間で、オフにもできる |
| BR-14 | 写真は期限なしで保存し、端末側で圧縮してから送る。サービスの終了時と、BR-16 で記録を消すときに消える |
| BR-15 | アカウントの削除（退会）時に、その利用者のデータを消す。おうちに投稿した記録の扱いは BR-16 に従う |
| BR-16 | おうちを抜けるとき、または退会するとき、自分が投稿した記録を残すかを本人が選ぶ。残さない場合は本人の投稿だけを消す |
| BR-17 | 記録には投稿時の投稿者名を保存する。アカウントが削除されても、残した記録の投稿者名を表示できるようにする |
| BR-18 | おうちには複数のユーザーと複数の猫を追加できる（例：ユーザー2人と猫2匹） |
| BR-19 | 最後の1人がおうちを抜けるときは確認画面を出し、おうちとその記録をすべて消す |
| BR-20 | 「いつもとの差」の判定方式は、統計的な外れ値と利用者が設定するしきい値から、設定で選ぶ。既定は統計的な外れ値とする |
| BR-21 | ユーザーが1人でも、記録はおうちの中で管理する |
| BR-22 | 独自の記録項目はおうちで共有し、ウィジェットのボタンは端末ごとに持つ |
| BR-23 | おうちの猫が1匹のときは、ウィジェットの猫の選択を省いてワンボタンで記録する |
| BR-24 | 猫のプロフィールの項目はすべて任意とする |
| BR-25 | 亡くなった猫は、記録を残したまま「お別れ」の状態にできる |

## 4. 機能要件（F-XX-xx）

| ID | 機能 | 段階 |
|---|---|---|
| F-RC-01 | ご飯・水・薬・おしっこ・うんち・吐いた・体重を記録する | 初回 |
| F-RC-02 | 量や状態などの詳細を任意で入力する | 初回 |
| F-RC-03 | 写真を添付する | 初回 |
| F-RC-04 | 自由メモを書く | 初回 |
| F-RC-05 | 利用者が独自の記録項目を追加する | 初回 |
| F-WG-01 | Android のウィジェットに利用者が登録したボタンを置き、押した後に猫を選んで記録する | 初回 |
| F-VW-01 | 1画面に1か月分のカレンダーを6行7列で表示し、各日のセルに記録の種類とメモの有無を小さなアイコンで示す | 初回 |
| F-VW-02 | セルを押すとその日の記録の一覧を表示し、記録を押すと詳細の確認と編集ができる | 初回 |
| F-VW-03 | 項目やメモで過去の記録を検索する | 第3段階 |
| F-ST-01 | 項目ごとの回数の推移と体重の折れ線グラフを、週と月で切り替えて表示する | 初回 |
| F-SH-01 | おうちに複数の猫を登録する | 初回 |
| F-SH-05 | 猫のプロフィール（名前、生年月日、性別、写真、持病）を登録する | 初回 |
| F-SH-06 | 猫を「お別れ」の状態にする | 初回 |
| F-SH-02 | おうちを作り、複数のアカウントで猫と記録を共有する | 初回 |
| F-SH-04 | メールでおうちへ招待する | 初回 |
| F-SH-03 | おうちを抜ける。その際に自分の投稿を残すかを選ぶ | 初回 |
| F-AU-02 | アカウントを削除する。その際に自分の投稿を残すかを選ぶ | 初回 |
| F-OF-01 | 通信できないときも記録し、後で同期する | 初回 |
| F-OF-02 | サーバーが停止していても記録と閲覧を続け、再開後に同期する | 初回 |
| F-OF-03 | アプリの起動時、手動の同期ボタン、アプリ実行中の5分おきの自動実行で同期する | 初回 |
| F-OF-04 | Android はアプリを閉じたときにタイマーを始め、バックグラウンドで15分おきに同期する。実行時刻の多少の遅れは許容する | 初回 |
| F-AU-01 | メールアドレスとパスワードでログインする（将来の公開も視野に入れる） | 初回 |
| F-AU-03 | パスワードをメールで再設定する | 初回 |
| F-AN-01 | 直近の傾向と比べて、いつもとの差を自動検知する | 次の段階 |
| F-NT-01 | 投薬などの予定を通知する | 次の段階 |
| F-NT-02 | いつもとの差を通知する | 次の段階 |
| F-NT-03 | 記録忘れを通知する | 次の段階 |
| F-NT-04 | 家族の記録を通知する | 次の段階 |
| F-NT-05 | 通知する内容を設定画面で選ぶ | 次の段階 |
| F-RP-01 | 獣医師向けのレポートを出力する | 次の段階 |
| F-AI-01 | 記録をもとに生成 AI で分析する | 次の段階 |
| F-EX-01 | 記録を CSV で出力する | 任意 |
| F-MD-01 | 通院、診断、検査結果、ワクチンの履歴を記録する | 第3段階 |
| F-MD-02 | 薬の名前、量、時刻を登録して投薬の予定を管理する | 次の段階 |
| F-BK-01 | サーバーのデータを定期的にバックアップする | PC へ移すまで |

## 6. 非機能要件（NF-XX-xx）

| ID | 内容 |
|---|---|
| NF-SC-01 | 通信はすべて暗号化する |
| NF-SC-02 | パスワードはハッシュ化して保存し、平文で保存しない |
| NF-SC-03 | ログインの試行回数を制限し、総当たり攻撃を防ぐ |
| NF-SC-04 | サーバーの API はすべて認証と認可を行い、自分が属するおうちのデータにだけアクセスできるようにする |
| NF-SC-05 | 鍵やトークンなどの秘密情報をアプリとリポジトリに入れない。生成 AI の呼び出しはサーバーから行う |
| NF-SC-06 | 配布物に署名し、依存ライブラリの脆弱性を CI で検査する |

## 7. 制約条件・前提条件（C-xx）

| ID | 内容 |
|---|---|
| C-01 | 利用者は2人を想定し、一般公開はしない |
| C-02 | ランニングコストは可能な限り発生させない |
| C-03 | サーバーは常時稼働を前提にしない |
| C-04 | リリース当初は AWS の無料枠で動かす（スクール課題のため）。AWS での環境の維持は3日程度の見込み |

| C-06 | 開発の期限と、スクール課題としての技術の指定はない |
| C-07 | アプリは公開リポジトリの GitHub Releases で配布する。アプリは誰でも入手できる前提で対策する |
| C-08 | PC へ移した後は Tailscale などの VPN で接続し、サーバーをインターネットに公開しない |
